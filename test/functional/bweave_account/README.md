# Bweave Python Utilities

Python utilities for creating and signing Blockweave transactions with Ethereum compatibility.

## Features

- **Load Web3 v3 Keystores**: Compatible with keystores generated by the C++ wallet
- **Transaction Signing**: secp256k1 ECDSA signatures with Keccak256 hashing
- **Ethereum Compatibility**: Uses Keccak256 + RLP encoding (future Ethereum integration)
- **Transaction Serialization**: Binary format compatible with C++ network protocol
- **Type Safety**: Full type hints and runtime validation

## Installation

```bash
cd test/functional/bweave_account
pip3 install --user -r requirements.txt
```

### Dependencies

- **pycryptodome** >= 3.18.0 - Keccak256 hashing (Ethereum standard)
- **eth-keys** >= 0.4.0 - secp256k1 signing
- **eth-account** >= 0.9.0 - Web3 keystore decryption
- **rlp** >= 3.0.0 - Recursive Length Prefix encoding

## Quick Start

### Basic Usage

```python
from bweave_account import BweaveAccount, Transaction, TxVersion, TransactionType

# Load account from keystore
account = BweaveAccount.from_keystore("wallet.json", "password")

# Create transaction
tx = Transaction(
    version=TxVersion.V0,
    nonce=1,
    from_address=account.address_bytes,
    tx_type=TransactionType.TRANSFER,
    data=b"Hello, Blockweave!",
    fee=1000
)

# Sign transaction
signing_hash = tx.generate_signing_hash()
r, s, v = account.sign_hash(signing_hash)
tx.attach_signature(r, s, v)

# Get transaction ID
tx_id = tx.compute_transaction_id()
print(f"Transaction ID: 0x{tx_id.hex()}")

# Serialize for network transmission
serialized = tx.serialize()
```

### Loading Accounts

```python
from bweave_account import BweaveAccount

# From Web3 keystore file (C++ wallet compatible)
account = BweaveAccount.from_keystore("wallet.json", "password")

# From hex private key
account = BweaveAccount.from_private_key_hex("0x1234...5678")

# From raw bytes
private_key = bytes.fromhex("1234...5678")
account = BweaveAccount(private_key)

# Get address
print(f"Address: {account.address}")  # 0x-prefixed checksummed
print(f"Address bytes: {account.address_bytes.hex()}")  # 20 bytes
```

### Creating Transactions

```python
from bweave_account import Transaction, TxVersion, TransactionType

tx = Transaction(
    version=TxVersion.V0,           # Currently only V0
    nonce=42,                        # Unique nonce
    from_address=account.address_bytes,  # 20 bytes
    tx_type=TransactionType.TRANSFER,    # Currently only TRANSFER
    data=b"Your transaction data here",
    fee=1000                         # Transaction fee
)

# Generate signing hash (Keccak256 of RLP-encoded fields)
signing_hash = tx.generate_signing_hash()

# Sign with account
r, s, v = account.sign_hash(signing_hash)
tx.attach_signature(r, s, v)

# Compute transaction ID (after signing)
tx_id = tx.compute_transaction_id()
```

### Serialization

```python
# Serialize to bytes (C++ compatible format)
serialized = tx.serialize()

# Deserialize from bytes
tx2 = Transaction.deserialize(serialized)

# Convert to dictionary (for JSON)
tx_dict = tx.to_dict()

# Create from dictionary
tx3 = Transaction.from_dict(tx_dict)
```

### Cryptographic Primitives

```python
from bweave_account import keccak256, sign, verify_signature

# Keccak256 hashing (Ethereum standard, NOT NIST SHA3)
hash_result = keccak256(b"hello")
print(f"Hash: 0x{hash_result.hex()}")

# Sign message hash
private_key = bytes.fromhex("1234...5678")
message_hash = keccak256(b"message")
r, s, v = sign(private_key, message_hash)

# Verify signature
from eth_keys import keys
pk = keys.PrivateKey(private_key)
public_key = pk.public_key.to_bytes()
is_valid = verify_signature(public_key, message_hash, (r, s, v))
```

### RLP Encoding

```python
from bweave_account import rlp_encode, rlp_encode_transaction, rlp_decode

# Encode basic types
encoded = rlp_encode(b"dog")
encoded = rlp_encode([b"cat", b"dog"])
encoded = rlp_encode([])

# Encode transaction fields
tx_data = [0, 1, b'\x12'*20, 0, b'hello', 1000]
encoded = rlp_encode_transaction(tx_data)

# Decode
decoded = rlp_decode(encoded)
```

## API Reference

### BweaveAccount

**Methods:**
- `__init__(private_key: bytes)` - Create from raw private key
- `from_keystore(keystore_path: str, password: str)` - Load from Web3 keystore
- `from_private_key_hex(hex: str)` - Load from hex string
- `sign_hash(signing_hash: bytes) -> tuple[bytes, bytes, int]` - Sign 32-byte hash

**Properties:**
- `address: str` - Ethereum address (0x-prefixed, checksummed)
- `address_bytes: bytes` - Address as 20 bytes
- `public_key: bytes` - 64-byte uncompressed public key

### Transaction

**Fields:**
- `version: int` - Transaction version (uint8)
- `nonce: int` - Unique nonce (uint64)
- `from_address: bytes` - Sender address (20 bytes)
- `tx_type: int` - Transaction type (uint8)
- `data: bytes` - Transaction payload
- `fee: int` - Transaction fee (uint64)
- `signature: Optional[bytes]` - 65-byte signature (r||s||v)

**Methods:**
- `generate_signing_hash() -> bytes` - Compute signing hash (Keccak256 of RLP)
- `attach_signature(r, s, v)` - Attach signature components
- `compute_transaction_id() -> bytes` - Compute transaction ID (after signing)
- `serialize() -> bytes` - Serialize to C++ compatible binary format
- `deserialize(data: bytes) -> Transaction` - Deserialize from bytes
- `to_dict() -> dict` - Convert to dictionary
- `from_dict(data: dict) -> Transaction` - Create from dictionary

### Enums

- `TxVersion.V0 = 0` - Transaction version 0
- `TransactionType.TRANSFER = 0` - Transfer transaction type

### Exceptions

- `BweaveError` - Base exception
- `KeystoreError` - Keystore loading/decryption errors
- `SignatureError` - Signature generation/verification errors
- `TransactionError` - Transaction creation/serialization errors
- `EncodingError` - RLP encoding errors

## Architecture

### Ethereum Compatibility

This Python implementation uses **Ethereum standards** for future compatibility:

| Component | Python (Ethereum) | C++ (Current) |
|-----------|------------------|---------------|
| Hashing | Keccak256 | SHA256 |
| Encoding | RLP | Custom binary |
| Signing | secp256k1 ECDSA | secp256k1 ECDSA |
| Keystore | Web3 v3 | Web3 v3 |

**Note:** The keystore format is compatible between C++ and Python, but transaction hashing differs. This allows Python to prepare for future Ethereum integration while C++ maintains current protocol.

### Transaction Signing Hash

```python
# Step 1: RLP encode transaction WITHOUT signature
tx_data = [version, nonce, from_address, tx_type, data, fee]
encoded = rlp.encode(tx_data)

# Step 2: Compute Keccak256 hash
signing_hash = keccak256(encoded)  # 32 bytes

# Step 3: Sign with secp256k1
r, s, v = sign(private_key, signing_hash)
```

### Transaction ID

```python
# RLP encode transaction WITH signature components
tx_data = [version, nonce, from_address, tx_type, data, fee, v, r, s]
encoded = rlp.encode(tx_data)

# Compute Keccak256 hash
tx_id = keccak256(encoded)  # 32 bytes
```

### Binary Serialization (C++ Compatible)

```
[version:1 byte]
[nonce:8 bytes big-endian]
[from:20 bytes]
[type:1 byte]
[data_len:4 bytes big-endian]
[data:variable]
[fee:8 bytes big-endian]
[signature_len:4 bytes big-endian]
[signature:65 bytes]
```

## Security Considerations

### Private Key Handling

- Never log or print private keys
- Use `bytes.fromhex()` carefully to avoid exposing keys in error messages
- The package uses eth-account which properly zeroes memory
- Consider using hardware wallets for production

### Keystore Security

- Web3 v3 keystores use:
  - AES-128-CTR encryption
  - scrypt KDF (N=262144, r=8, p=1)
  - keccak256 MAC for integrity
- Always use strong passwords
- Store keystores securely (encrypted filesystem recommended)

### Signature Verification

- Signatures use secp256k1 ECDSA (same as Bitcoin/Ethereum)
- Recovery ID (v) allows public key recovery from signature
- Always verify recovered public key matches expected sender

## Troubleshooting

### Import Errors

```python
ModuleNotFoundError: No module named 'Crypto'
```

**Solution:** Install pycryptodome (not pycrypto):
```bash
pip3 install --user pycryptodome
```

### Wrong Password Error

```python
KeystoreError: Decryption failed (wrong password?): MAC mismatch
```

**Solution:** The password is incorrect. The MAC verification ensures the password is correct before attempting decryption.

### Invalid Transaction Fields

```python
ValueError: from_address must be exactly 20 bytes, got 40
```

**Solution:** Use `bytes.fromhex()` to convert hex addresses to bytes:
```python
from_address = bytes.fromhex("1234567890123456789012345678901234567890")
```
